Linux System Monitoring Script

Overview

A Bash script that performs a basic health check of a Linux system.

The script displays:

* Hostname, uptime, and current user
* CPU, memory, and disk information
* Running processes
* Disk usage warnings (80%+)
* Docker service status

Commands Practised

* hostname
* uptime
* whoami
* top
* free
* df
* ps
* awk
* tr
* systemctl

What I Learned

* Working with Bash variables
* Command substitution $(...)
* Pipes |
* Conditional statements (if, else, fi)
* Basic Linux system monitoring and automation
