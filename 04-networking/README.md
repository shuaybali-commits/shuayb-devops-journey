# Networking

This module introduces the fundamentals of computer networking, covering how systems communicate within and across networks.

Networking is a core DevOps skill that underpins cloud infrastructure, containers and distributed applications.

---

## Directory Structure

This module is organised into three sections to support both learning and practical application:

- [Notes](./notes)  
  Key concepts and explanations related to networking fundamentals.

- [Labs](./labs)  
  Hands-on exercises exploring real-world networking scenarios.

- [Projects](./projects)  
  Practical implementations demonstrating applied networking knowledge.

---

## Topics Covered

- IP addressing and DNS
- HTTP/HTTPS protocols
- Ports and sockets
- Client-server communication
- Reverse proxies and load balancing
- Cloud networking fundamentals

---

## Purpose

Networking is a fundamental DevOps skill. This module develops the knowledge required to design, troubleshoot and manage communication between applications, services and cloud infrastructure.
